☁️ 1분 완성! 무료 Streamlit Community Cloud 배포 가이드

수강생님의 GitHub Repository와 연결하여 무료 클라우드에 3초 만에 올리는 방법입니다.

  1. Streamlit Community Cloud ↗에 접속하여 Sign in with GitHub로 로그인합니다.
  2. 오른쪽 상단의 [New app] 버튼을 클릭합니다.
  3. 배포 설정창에서 다음 정보를 기입/선택해 줍니다:
    • Repository: ejbtsj1259-dotcom/project1_info_crawler_resend
    • Branch: main
    • Main file path: app/streamlit_app.py
  4. [Deploy!] 버튼을 누르면 실시간으로 동적 Streamlit 사이트가 전 세계에 무료 배포됩니다!
  5. (팁) Resend 이메일 실제 발송을 위해 대시보드 우측 하단 Settings -> [Secrets] 창에 RESEND_API_KEY 등의 .env 변수들을 입력하여 안전하게 보관할 수 있습니다.
